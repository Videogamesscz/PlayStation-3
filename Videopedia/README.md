# Videopedia PS3)

**¡Encuentra tu tutorial de PS3 fácilmente!**

## 🔥 Características principales

* **📂 Estructura perfecta:** Busca tu tutorial de manera más fácil con descripción de cada vídeo.
* **✅ Cero complicaciones:** Interfaz visual sencilla con botones de colores.

---

## 📖 Instrucciones de uso

1.  **Descarga la aplicación** a tu ordenador.
2.  Abre la aplicación **`Videopedia.exe`**.
    * *Nota: Si Windows te muestra una advertencia azul ("Protegió su PC"), pulsa en "Más información" -> "Ejecutar de todas formas". Es normal porque la app es casera y no tiene firma digital de Microsoft.*
3.  **Selecciona la letra** de tu USB en el menú desplegable.
4.  🔴 **Paso 1 (Busca tu tutorial por categoría)
5.  🟢 **Paso 2 (Reproduce el tutorial):** Dale a "Reproducir".
6.  ¡Listo! Disfruta del contenido.

---

## 📋 Requisitos
* Un ordenador con Windows.
* Conexión a Internet (para ver el tutorial).
